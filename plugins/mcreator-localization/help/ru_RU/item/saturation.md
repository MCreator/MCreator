Насыщение игрока уменьшается, когда тот активно чем-либо занимается, и должно быть полностью исчерпано, прежде чем начнёт падать уровень шкалы сытости.

Данный множитель используется игрой для определения итоговой величины насыщения от употребления этого предмета. Значение рассчитывается по формуле:

```
Итоговое насыщение = Прежнее насыщение игрока + (2 * Пищевая ценность * Модификатор насыщения)
```
Итоговое насыщение ограничивается игрой так, чтобы не превышать максимальную величину шкалы голода игрока.

Как и в случае с голодом, 1 единица насыщения равна 1/2 деления шкалы голода, а максимальное значение составляет 20 единиц. Однако, для насыщения не предусмотрена отдельная шкала в интерфейсе игрока.
