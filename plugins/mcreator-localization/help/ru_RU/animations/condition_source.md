Задаёт источник условия проигрывания анимации.

По умолчанию условие определяется процедурой, указанной в "Условии проигрывания".

Также в виде источника условия можно указать параметр данных этой сущности логического типа. В этом случае анимация будет воспроизводиться, пока заданному параметру данных присвоено истинное значение, а выбранная процедура будет игнорироваться.
