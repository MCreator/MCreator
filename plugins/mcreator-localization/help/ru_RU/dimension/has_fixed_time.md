Отметьте, чтобы зафиксировать указанное значение времени в этом измерении.

Начиная с 26.1, эта настройка применяется только к измерениям, где есть смена дня и ночи — с эффектами Верхнего мира, либо с пользовательскими эффектами при указании типа неба "NORMAL". В других случаях время всегда будет фиксированным.
