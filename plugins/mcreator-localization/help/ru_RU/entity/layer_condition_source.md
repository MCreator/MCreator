Позволяет задать источник условия видимости слоя модели.

По умолчанию, условие видимости слоя определяется выбранной из списка процедурой со значением.

Однако, в качестве источника можно выбрать параметр данных сущности логического типа. Тогда слой модели будет виден, пока заданному параметру присвоено истинное значение, а указанная процедура будет игнорироваться.
