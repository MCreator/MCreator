Здесь можно указать способ определения состояний данного блока: "Выбор" (по умолчанию) или "Компоновка".

В режиме "Компоновка", каждая запись определяет независимую часть модели блока. Все части, условиям которых соответствует состояние блока, прорисовываются вместе.

В отличие от режима "Выбор", условия записей могут использовать любые из свойств состояния блока, причём части с пустыми условиями видны всегда. Также допускается указание одинаковых условий для прорисовки нескольких частей модели одновременно.

Модель этого блока по умолчанию в режиме "Компоновка" не прорисовывается; вместо этого следует добавить запись состояния с пустым условием. Однако, эта модель всё так же используется для предмета/предпросмотра блока. К частям применяется текстура частиц блока по умолчанию; собственные текстуры частиц записей состояний используются только в режиме "Выбор".

Если части определяют собственные рамки-границы, форма блока получается объединением форм всех частей, условиям которых удовлетворяет состояние блока. Рамка-граница по умолчанию в этом случае игнорируется, а в состояниях, когда подходящие части не задают рамку-границу, у блока будет пустая форма; для определения основной рамки-границы блока следует добавить запись состояния с пустым условием.

Если включён поворот блока, MCreator автоматически настроит поворот всех частей модели вместе с блоком.
