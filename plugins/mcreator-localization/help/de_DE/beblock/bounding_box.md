Begrenzungsboxen definieren die Kollisionsform und den Umriss des Blocks. Jeder Eintrag ist eine Box
angegeben in 1/16 eines Blocks, gemessen von dessen unterer nordwestlicher Ecke.

Bedrock Edition-Limits:

- Boxen müssen innerhalb des Blocks bleiben: X und Z von 0 bis 16, Y von 0 bis 24
- Es wird nur ein Umriss unterstützt, sodass der Umriss alle Boxen zusammen umrandet und höchstens 16 hoch ist
- Boxen können nicht voneinander abgezogen werden

Wenn der Block Rotation nutzt, werden die Boxen zusammen mit dem Blockmodell gedreht.
