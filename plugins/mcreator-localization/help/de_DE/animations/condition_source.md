Wählt die Quelle der Animations-Wiedergabebedingung aus.

Standardmäßig wird die Bedingung von der Prozedur in der Auswahl für Wiedergabebedingungen angegeben.

Alternativ kann ein logischer Datentyp-Eintrag dieser Entität als Bedingungsquelle ausgewählt werden.
In diesem Fall wird die Animation abgespielt, während der Datensatz der ausgewählten Entität auf true gesetzt ist
und die Wiedergabebedingungen der Prozedur werden ignoriert.
