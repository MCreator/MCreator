Si ce paramètre est activé, le temps sera fixé à la valeur donnée à l'intérieur de cette dimension.

À partir de 26.1, ce paramètre ne s'applique qu'aux dimensions avec un cycle jour/nuit : effets Overworld par défaut, ou effets personnalisés avec le type de ciel NORMAL. Les autres combinaisons donnent toujours une heure fixe (pas de timeline).
